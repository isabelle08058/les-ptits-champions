# Les p’tits champions de Terre-Sainte — site 2027

Contenu :
- index.html : site public
- styles.css : design responsive
- script.js : navigation mobile
- admin.html : première interface d’administration
- README.md : instructions

IMPORTANT
La version actuelle est un site statique complet côté visiteur. L’interface admin fournie fonctionne sur l’appareil utilisé, via localStorage. Elle n’est pas encore un CMS partagé en ligne : pour que les modifications effectuées depuis l’administration soient visibles par tous les visiteurs, il faut connecter l’éditeur à une base/stockage en ligne et publier le site sur un hébergeur.

Étape suivante recommandée :
1. Mettre ces fichiers sur un hébergeur.
2. Connecter l’administration à un stockage en ligne.
3. Relier le formulaire d’inscription à une adresse e-mail ou une base de données.
4. Ajouter les Conditions générales et la fiche sanitaire en téléchargement.
5. Une fois l’adresse définitive obtenue, créer le QR code permanent vers cette adresse.
